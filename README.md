# MyGomel

Django-сайт о городской жизни Гомеля: интерактивная карта муралов, новости,
история города и фотогалерея благоустройства "до/после".

## Разделы

- **Муралы** — карта на Leaflet с метками по адресам, страница каждого
  мурала с фото/видео и комментариями, форма "предложить мурал"
- **До/после** — парные фото мест города до и после благоустройства
- **История** — карточки исторических мест и событий с фотографиями
- **Новости** и раздел мероприятий колледжа (учебные, общежитие, культурные)

Если у мурала не указаны координаты, они определяются автоматически по
адресу через геокодер OpenStreetMap (Nominatim) при сохранении записи.

## Стек

- Python, Django 5
- MySQL (через PyMySQL)
- Leaflet.js для карты
- Gunicorn, деплой на Vercel

## Запуск локально

```bash
cd itsgomel
cp .env.example .env
# указать параметры своей MySQL-базы в .env

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
